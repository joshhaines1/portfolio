# Josh Haines — Portfolio

Personal portfolio site for Josh Haines, live at [www.joshhaines.dev](https://www.joshhaines.dev).

## Sections

- **Intro / About** – introduction and skills
- **Resume** – work experience and education
- **Projects** – personal development projects (Betify, Pure Poker)
- **Services / Stats** – frontend, backend, and cloud experience
- **Business Info** – Josh Haines LLC
- **Contact** – contact form

## Tech

Static site built with plain HTML, CSS, and JavaScript (jQuery, with a few small plugins). There is no build step.

## Project structure

```
index.html     Main page
styles.html    Style demo / reference page
css/           Stylesheets (base, main, vendor, fonts, icon sets)
js/            Scripts (main.js plus vendor libraries)
fonts/         Lora and Poppins web fonts
images/        Logos, headshot, backgrounds, project images
app-ads.txt    Ad network seller declarations
CNAME          Custom domain for GitHub Pages
```
